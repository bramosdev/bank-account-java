# Bank Account Java

Sistema bancário desenvolvido em Java para simular operações básicas de uma conta bancária por meio de uma interface de terminal.

## Sobre o projeto

Este projeto foi desenvolvido para aplicar na prática fundamentos da linguagem Java na construção de uma aplicação interativa.

O sistema mantém o saldo da conta durante a execução e permite realizar diferentes operações através de um menu.

## Funcionalidades

- Consulta de saldo
- Depósito de valores
- Saque de valores
- Atualização do saldo após cada operação
- Menu interativo
- Validação de opções do menu
- Encerramento seguro da aplicação

## Tecnologias

- Java
- Git
- GitHub

## Conceitos aplicados

- Variáveis e tipos de dados
- Operadores aritméticos
- `Scanner` para entrada de dados
- `switch/case`
- Estrutura de repetição `while`
- Controle de fluxo
- Atualização de estado durante a execução
